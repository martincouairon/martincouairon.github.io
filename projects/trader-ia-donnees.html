DonnéesData

Les fichiers de données de l'expérience, tels qu'ils sont à la date d'arrêt du rapport.

The experiment's data files as of the report cut-off date. Column names are in French.

RapportReport DécisionsDecisions CalculsCalculations DonnéesData

Chaque fichier est une table CSV. Les fichiers écrits par le trader et par le mesureur ne sont jamais réécrits : une correction est une nouvelle ligne. Les fichiers produits par les scripts sont recalculés à chaque mesure. Le sens de chaque colonne est décrit dans le dictionnaire des données ; l'historique complet est dans le dépôt.

Cliquer sur un en-tête de colonne trie la table.
